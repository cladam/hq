A command-line HML query and stream processor written in [hica](https://www.hica.dev).

`hq` is a lightweight and flexible command-line HML processor for HML data. It's written in hica and has zero runtime dependencies, allowing you to easily slice, filter, map, and transform structured data.
=======
## Usage

```sh
hica build   # compile to binary
hica run     # compile and run
hica fmt     # format according to hica style guide
hica check   # type-check without emitting
hica clean   # remove generated files
```
